# Changelog

## 2.1.0

- With [Effect Select](https://github.com/SlamHammerfist/effect-select) active, the Roll Messages
  keys appear in the Attribute Key dropdown with readable names: every roll type, and the ability,
  skill, tool, death, concentration, action type and attack mode tags.

## 2.0.0

First release as a system module for the Roll Messages hub, for Foundry VTT v14 and D&D 5e 6.0.

- Messages for attack, damage, check, save and initiative rolls in the dnd5e roll dialogs, shown
  above the dialog's configuration section.
- Tags for ability, skill, tool, death and concentration saves, and for attack and damage action
  type, item type, activity type and attack mode.
- Clicked bonuses go into the first roll's situational bonus.
